# Mexican Sign Language (LSM) Electronic Interpreter
Real-time intelligent system for Mexican Sign Language (LSM) recognition and translation using computer vision, Deep Learning, and landmark processing.

Official repository for the research and university social service project focused on developing an assistive technological prototype. 
The system leverages Computer Vision (MediaPipe) for joint coordinate extraction and Deep Learning models (TensorFlow/Keras) for real-time classification of static signs in Mexican Sign Language.

# Intérprete Electrónico de Lengua de Señas Mexicana (LSM)
Sistema inteligente en tiempo real para el reconocimiento y traducción de la Lengua de Señas Mexicana (LSM) mediante visión por computadora, Deep Learning y procesamiento de landmarks.

Repositorio oficial del proyecto de investigación y servicio social orientado al desarrollo de un prototipo tecnológico asistencial. 
El sistema utiliza técnicas de Visión por Computadora (MediaPipe) para la extracción de coordenadas articulares y modelos de Deep Learning (TensorFlow/Keras) para la clasificación en tiempo real de señas estáticas de la Lengua de Señas Mexicana.
